# David Light Lab

**An interactive 3D reference for drawing, painting and studying light.**

> Turn the sculpture. Move the light. Study the form.

David Light Lab is an artist-focused browser tool built around a real 3D scan of Michelangelo's *David*. It is designed as a live studio reference rather than a general-purpose 3D viewer.

Live demo: https://salmonofdoubt.github.io/demos/david-light-lab/

Standalone repository: https://github.com/salmonofdoubt/david-light-lab

## What it does

- free three-axis sculpture rotation, including roll;
- separate camera orbit, pan and zoom;
- Mac trackpad panning without a mouse;
- explicit Pan X / Pan Y controls plus Centre subject;
- perspective and orthographic projection;
- front, three-quarter, profile and back presets;
- independently controllable key light and fill;
- light softness/form-transition control;
- world-locked or head-locked lighting;
- plaster, grayscale, 3-value, 5-value and silhouette modes;
- A-series and common canvas ratios;
- portrait/landscape crop frames;
- halves, thirds and diagonal composition guides;
- independent camera, light and crop locks;
- Paint Mode for a stable live reference;
- local study save/restore;
- shareable study-state links;
- random study generator and timer;
- PNG reference export;
- installable PWA shell.

## Controls

**Explore**
- drag: rotate the sculpture;
- two-finger Mac trackpad movement: pan;
- pinch / wheel: zoom;
- Shift + drag: roll;
- Option/Alt + drag: orbit the camera.

**Compose**
- click-drag: place/pan the sculpture;
- two-finger Mac trackpad movement: pan;
- pinch: zoom;
- Camera panel: precise Pan X / Pan Y and Centre subject.

**Paint**
- locks the reference and hides the studio interface for sustained drawing or painting.

## Reproducibility

`tools/build_mesh.py` downloads the source STL and deterministically rebuilds the browser mesh by cropping the upper statue, reorienting, welding coincident vertices, removing degenerate triangles, aligning face winding and computing smooth vertex normals.

## Privacy and analytics

Study state is stored locally in the browser when **Save study** is used. Shared study links encode their state in the URL. No drawing is uploaded by David Light Lab. The web page includes Cloudflare Web Analytics.

## Testing

The Playwright visual test covers desktop and mobile loading/rendering, the mobile control drawer, Compose drag panning, explicit Pan X/Pan Y controls, Mac-trackpad-style two-finger pan events, and lit/flat rendering diagnostics.
